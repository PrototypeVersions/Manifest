FIRST LAUNCH

Install once.
Manifest handles the rest.

This alpha is already functional, but it is not yet notarized with Apple or production-signed for Windows. That means your operating system may show a security confirmation the first time you open it.

MACOS

If macOS says it cannot verify Manifest

Drag Manifest into Applications first. Then open System Settings → Privacy & Security and choose Open Anyway. You should only need to approve that installed copy once.

WINDOWS

If Windows shows SmartScreen

Choose More info, verify the app is Manifest, then choose Run anyway. Production signing will remove most of this friction later.

ALPHA SOFTWAREBuilt for testing the core Manifest experience.

Manifest currently starts with a conservative local model so the installation path is dependable. The model catalog, stronger automatic recommendations, upgrades, and broader task routing will expand from here.
