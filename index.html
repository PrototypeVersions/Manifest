Install or start Ollama to make the models on this computer available inside Manifest.

Set Up Ollama →
  1. Install Ollama. If you do not have it yet, use the official Ollama download below.
  2. Start Ollama. Open the Ollama app, or run ollama serve.
  3. Allow Manifest if needed. If Ollama is running but Manifest still cannot connect, add https://prototypeversions.github.io to OLLAMA_ORIGINS, then restart Ollama.
  4. Return here and scan again. Your installed Ollama models should appear automatically.

Start LM Studio’s local server to make its downloaded models available inside Manifest.

Set Up LM Studio →
  1. Install and open LM Studio. Download it below if it is not already installed.
  2. Download a local model in LM Studio if you do not already have one.
  3. Start the API server. Open the Developer page and turn on the server. The normal address is http://localhost:1234.
  4. Enable browser access. Turn on Enable CORS in LM Studio’s server settings. If you enabled authentication, paste the API token above.
  5. Return here and scan again. Manifest should list the models exposed by LM Studio.
