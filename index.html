You do not need Ollama to use the Manifest browser demo. Connect it only if you already use Ollama or want to experiment with an external local runtime.

Connect Existing Ollama →
  1. Install Ollama only if you want this advanced integration.
  2. Start Ollama. Open the Ollama app, or run ollama serve.
  3. Allow Manifest if needed. If Ollama is running but Manifest still cannot connect, add https://prototypeversions.github.io to OLLAMA_ORIGINS, then restart Ollama.
  4. Return here and scan again. Existing Ollama models should appear automatically.

Connect Existing LM Studio →
  1. Install and open LM Studio only if you want this advanced integration.
  2. Use a model already downloaded in LM Studio.
  3. Start the API server. Open the Developer page and turn on the server.
  4. Enable browser access. Turn on Enable CORS in LM Studio’s server settings. If authentication is enabled, paste the API token above.
  5. Return here and scan again. Manifest should list the models exposed by LM Studio.
